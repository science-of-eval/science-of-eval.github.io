# SciEval: Workshop on the Science of Evaluation (ICLR 2027)

Source for https://science-of-eval.github.io/ — a single static page (`index.html`) served by GitHub Pages. No build step.

## Editing
- All content and styles live in `index.html`.
- Photos are in `images/people/<first-last>.jpg` (square, 480×480), taken from each person's homepage.
  Han Jiang currently shows initials; to add a photo, save `images/people/han-jiang.jpg` and swap the initials `<span>` for an `<img>` (see the comment in `index.html`).
- **Contact email:** placeholder in the footer (search for `TODO`).
- **Submission link:** update the "Submission" box in the Call for Papers section once the OpenReview venue is live.
